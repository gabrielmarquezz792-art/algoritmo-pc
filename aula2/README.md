## Exercício 1 — Perímetro da circunferência

**Contexto:** Em uma oficina mecânica, muitas peças possuem formato circular, como rolamento, engrenagens e polias. Para calcular a quantidade de material necessária para fabricar uma proteção ao redor de uma peça circular, o técnico precisa conhecer o comprimento da borda dessa peça, ou seja, o perímetro da circunferência.

**Enunciado:** Desenvolva um programa em C que leia o valor do raio de uma peça circular (em centímetros), calcule o perímetro da circunferência usando a fórmula:

```
perímetro = 2 * pi * raio
```

e exiba o resultado com duas casas decimais.

**Entrada:**
```
Qual a medida do raio (em cm)?
> 5.30
```

**Saída:**
```
O perímetro da circunferência é 33.29 cm
```

## Exercício 2 — Perímetro e área de um jardim retangular

**Contexto:** Uma empresa de paisagismo está elaborando o projeto de um jardim retangular. Para instalar uma cerca ao redor do jardim, é necessário conhecer o seu perímetro, e para calcular a quantidade de grama que será utilizada, é preciso determinar a área do terreno.

**Enunciado:** Desenvolva um programa em C que leia o comprimento e a largura de um jardim retangular (em metros); calcule o perímetro do jardim utilizando a fórmula:

```
perímetro = 2 * (comprimento + largura)
```

e a área do jardim utilizando a fórmula:

```
área = comprimento * largura
```

Ao final, exiba os resultados com duas casas decimais.

**Entrada:**
```
Qual o comprimento do jardim (m)?
> 12.50
Qual a largura do jardim (m)?
> 8.00
```

**Saída:**
```
Perímetro do jardim: 41.00 m
Área do jardim: 100.00 m²
```

## Exercício 3 — Tempo de gestação em meses

**Contexto:** Durante o acompanhamento gestacional, é comum que o tempo de gestação seja informado em semanas. Para fins de estimativa, considere que cada semana possui 7 dias e que um mês possui 30 dias.

**Enunciado:** Elabore um algoritmo e um programa em linguagem C que leia a quantidade de semanas de gestação e calcule a quantidade aproximada de meses correspondentes.

**Entrada:**
```
Qual a quantidade de semanas de gestação?
> 9
```

**Saída:**
```
Tempo de gestação aproximado: 2.1 meses
```

## Exercício 4 — Consumo diário de água recomendado

**Contexto:** Em uma Unidade Básica de Saúde, uma equipe deseja estimar o consumo diário de água de um paciente. Para uma orientação inicial, considera-se a recomendação de 35 ml de água por quilograma de massa corporal.

**Enunciado:** Elabore um algoritmo e um programa em C que leia a massa corporal de uma pessoa, em quilogramas, e exiba a quantidade aproximada de água recomendada por dia em litros.

**Entrada:**
```
Digite a massa corporal (em kg):
> 70
```

**Saída:**
```
Quantidade aproximada de agua recomendada por dia: 2.5 litros
```

## Exercício 5 — Média aritmética de duas notas

**Contexto:** Em um sistema acadêmico, as notas das avaliações são armazenadas com valores reais, permitindo registrar frações de ponto. Para apresentar o desempenho parcial do estudante, é necessário calcular a média aritmética das duas avaliações realizadas.

**Enunciado:** Elabore um algoritmo e um programa em linguagem C que leia as duas notas de um aluno e exiba sua média aritmética, apresentando o resultado com duas casas decimais.

**Entrada:**
```
Digite a primeira nota: 7
Digite a segunda nota: 8
```

**Saída:**
```
Media aritmética: 7.50
```
